# 💫 About Me

Senior Software Engineer focused on backend systems, platform engineering, and infrastructure automation.

I work across distributed systems, Kubernetes, GitOps, observability, and developer tooling — with a strong interest in self-hosted infrastructure and reproducible environments.

Most of my recent work revolves around:
- scalable backend architecture
- cloud-native infrastructure
- automation with Ansible/Terraform
- Kubernetes + ArgoCD ecosystems
- event-driven and distributed systems
- developer productivity tooling

> Building observable, reproducible, and operationally simple systems.

Outside of work, I actively experiment with homelab infrastructure, self-hosting, shell tooling, and emerging AI-assisted engineering workflows.
